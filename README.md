# מד ק״מ

האתר שומר את 24 ערכי הקילומטראז׳ בטבלת Supabase ומשתף אותם בין מכשירים. הסנכרון מתעדכן אוטומטית כל כמה שניות.

## חיבור Supabase

1. צרו פרויקט ב־[Supabase](https://supabase.com/) ושמרו את ה־Project URL ואת מפתח ה־publishable הציבורי.
2. בעורך SQL של הפרויקט הריצו את הקובץ `supabase.sql`.
3. פתחו את `config.js` והחליפו את `YOUR_PROJECT_ID` ואת `YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY` בערכים מהפרויקט.
4. פרסו את `index.html`, `styles.css`, `app.js` ו־`config.js` באותו אתר סטטי.

אם יש ערכים שמורים בדפדפן הזה והטבלה בענן עדיין ריקה, האתר יעתיק אותם לענן בחיבור הראשון. אם כבר יש נתונים בענן, הענן יהיה המקור הקובע.

## הרשאות

ההגדרה הנוכחית מאפשרת לכל מי שיכול לפתוח את האתר לקרוא ולעדכן את כל 24 הערכים, ללא התחברות. מפתח publishable מיועד לשימוש בדפדפן ומוגבל על ידי מדיניות RLS; לעולם אין לשים בקובץ `config.js` מפתח secret או `service_role`. אם הקישור צריך להיות פרטי, צריך להוסיף התחברות ולהחליף את מדיניות הגישה הפתוחה.
